# Dananz

Полная главная страница по макету Dananz на HTML и CSS: хедер, первый экран, About, Services, Product, Material, контактный блок и футер.

Для просмотра откройте `index.html` в браузере. Интернет и установка зависимостей не нужны: изображения и шрифты Poppins находятся в `assets`.

Макет рассчитан на экран шириной 1440 px. Адаптивной вёрстки и JavaScript нет. Для наведения используются только CSS-переходы. Навигация и кнопки разделов работают через якоря. Подписка и кнопки социальных сетей представлены как элементы вёрстки, без отправки данных. Внутренние страницы не входят в этот проект.
