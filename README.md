# Dananz

Вёрстка по макету Dananz на HTML и CSS: хедер, первый экран со статистикой и блок About.

Для просмотра откройте `index.html` в браузере. Интернет и установка зависимостей не нужны: изображения и шрифты Poppins находятся в `assets`.

Макет рассчитан на экран шириной 1440 px. Адаптивной вёрстки и JavaScript нет. Для наведения используются только CSS-переходы. Остальные страницы и действия кнопок пока не реализованы.
